# data/

Данные проекта. Крупные файлы (полноценные 3DGS-сцены, многоракурсные фото)
не хранить в системе контроля версий без Git LFS — см. `.gitignore` в корне.

- `raw/test_models/` — скачанные тестовые 3D-модели (mesh, OBJ/PLY) для
  локальной отладки геометрических операций. См. `data_sources.md`. Также
  содержит `sample_gaussians.ply` — синтетический Gaussian Splat, сгенерированный
  из `spot.obj` скриптом `scripts/generate_sample_gaussian_ply.py` (не хранится
  в git, см. `.gitignore`; перегенерировать при необходимости) — тестовые
  данные для `src/viewer/`.
- `raw/` (остальное) — прочие исходные, неизменённые данные (многоракурсные
  фотографии сцен, калибровочные данные камер и т.п.) по мере скачивания.
- `processed/` — данные после предобработки (например, результат COLMAP,
  подготовленные для обучения 3DGS point cloud + позы камер).
- `gaussian_scenes/` — обученные/сохранённые 3DGS-сцены (baseline и
  отредактированные версии), используемые как вход для экспериментов
  редактирования и как объект итоговых сравнений. Сейчас содержит три
  скачанных из интернета реальных примера для проверки `src/viewer/`
  (не хранятся в git — см. `.gitignore` и `data_sources.md` §4.2):
  `train_tanksandtemples/` (уличная сцена, 176 МБ), `luigi/` (фигурка,
  0.97 МБ), `bonsai_sfm_pointcloud/` (сырое SfM-облако точек, 5.4 МБ).
- `data_sources.md` — откуда взяты все данные, лицензии, ссылки на скачивание
  полноразмерных бенчмарков.
